Deterministic projectile ballistics

                  
Bind authored single-target towers to direct or arc fixed-travel projectiles. Flight remains inert until this profile is selected.

                

                Ballistics v1
              

              
This future Ballistics schema is preserved read-only.

              
              
Allowed fields: projectiles.towers.{towerId}.{trajectory, travelTimeUnits, maxAltitude, ricochet.{maxBounces, rangeCells}}, optional clearance.terrainBlockerHeights, and ricochet surfaces in terrainTags or armorTypes. Arc requires maxAltitude; direct forbids it.

Authored counter pool

                  
The deterministic policy may only add these authored groups. Conditions can inspect damage distribution, coverage, movement layers, and Logistics brownout.

                

              

              
              
Each counter declares label, integer priority, conditions, wave groups, and threatCost. The shared engine validator checks references and limits before save.

            

            

              
Threat budget
Caps adaptation without rewriting an authored wave.

              

                
                
              

            

            

              
Fairness caps
Limits when and how often the Director can select a counter.

              

                
                
                
                
              

            

          

          

            

            

            

              

                

                  
Procedural challenge pool

                  
Author weighted battle-local objectives. The engine selects them deterministically only when this profile is enabled for the mission.

                

              

              

                
              

              
              
Definitions use a positive weight and either kill_with_source or preserve_shield. Shared engine validation checks source references and all limits during Preview.

            

            

              

                
Seeded generation preview
Read-only preview of the currently saved and active mission profile. This preview never simulates gameplay and never writes unsaved draft changes.

                
              

              
              
Enable and save this profile before previewing its seeded selection.

            

          

          

            

            

            

              

                

                  
Boss components and targeting

                  
Define bounded component HP, shields, hit regions, tags, typed ability suppression, and tower priorityTags. Shared engine validation remains authoritative.

                

              

              
              
R12.1 has no manual component command. Towers route damage only through explicit targeting bindings; removing or disabling the module restores root targeting.

            

            

              

                

                  
Enemy formations

                  
Bind authored enemy types to bounded vanguard, body, and support cohorts. Dynamic-flow navigation remains authoritative; the engine computes steering.

                

              

              
              
Each cohort defines members and neighborRadius, cohesionWeight, separationWeight, and roleWeight. Preview performs the authoritative closed-schema and dynamic_flow validation.

            

            

              

                

                  
Vanguard protection

                  
Add optional protection to a formation cohort. A selected Combat profile must provide root shields for every authored vanguard type.

                

              

              
Protection fields and bounds are loaded from the shared engine descriptor.

Single-player projects do not load the multiplayer runtime.

Welcome to TowerForge Editor

      
    

    

      
Design a complete tower-defense game from data — then play it instantly. Here's the loop:

      

        
1 · Author
Edit Enemies, Towers, Waves and Missions in the sidebar. Sliders, level ladders and pickers — no JSON.

        
2 · Playtest
Open Playtest to drop towers and run waves live on your unsaved project.

        
3 · Tune
Sim charts the difficulty curve; the top-bar pill flags broken references as you type.

        
4 · Ship
Build Targets emits a playable web bundle. Enable MCP in Settings to let AI agents help.
